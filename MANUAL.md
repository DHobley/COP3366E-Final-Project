1. User Manual for Community Cultural Festival Management Application

2. Running the App
    - Open the solution in Visual Studio.
    - Build the project.
    - Run the app to open the GUI.

3. Adding a Participant
    - Enter Name, Contact Info, Fee.
    - Select a category (Dance, Music, Art, Culinary).
    - Check "Valid Registration" if applicable.
    - Click "Add Participant".

4. View Data
    - Participants will be listed in the main window.
    - Summary info (total revenue, participants) will be added later.
  
5. Accessibility
    - Keyboard navigation supported via Tab order.
    - Large text supported (font size options coming soon).
